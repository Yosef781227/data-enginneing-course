Go back in time

Think of it like…

A shared document with version history. Every time someone changes it, a new version is saved. You can open any old version to see how it looked.

A Delta table keeps a list of every change. This list is called the transaction log.

DESCRIBE HISTORYshows the list of versions.
VERSION AS OFreads the table as it was at one version.

This is called time travel. It is often on the exam.

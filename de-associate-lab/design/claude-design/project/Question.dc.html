A data engineer uses Auto Loader to read new JSON files. Some new files have extra columns. Which setting lets Auto Loader add those new columns to the table’s schema?

{{banner.title}} {{banner.sub}}
Careful: the source answer may be wrong The question bank says A. The Databricks docs say B is the setting that adds new columns. We count B as right here.

The idea being tested

Schema evolution: what happens when new data has columns the table has never seen. Think of a form that suddenly gets a new question. Do you add the question, ignore it, or stop?

Why B is right

schemaEvolutionMode tells Auto Loader what to do with new columns. addNewColumns means: stop once, add the column to the schema, then keep going on the next run.

Why the others are wrong

A

Makes Auto Loader guess real types (number, date) instead of text. It does not add columns.

C

This is for writing to Delta, and false turns new columns off. The opposite of what we want.

D

Only says which file type to read (JSON). It has nothing to do with columns.
